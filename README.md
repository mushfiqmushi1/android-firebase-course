# Android + Firebase: Full Course 🔥

Connect Firebase to your Android app — from project setup to a complete
app with **Google Sign-In**, Firestore database, Storage and push notifications.

## Learning path

| # | File | What you will learn |
|---|------|---------------------|
| 1 | `01_android_studio_setup.md` | Install Android Studio, create your first project (Kotlin) |
| 2 | `02_firebase_console_setup.md` | Create a Firebase project, add your app, google-services.json, Gradle setup |
| 3 | `03_email_password_auth.md` | Sign up / sign in / sign out with email & password |
| 4 | `04_google_sign_in.md` | **Google Sign-In** with Firebase Auth (SHA-1, web client ID, full code) |
| 5 | `05_firestore_crud.md` | Cloud Firestore: create, read (realtime), update, delete, queries |
| 6 | `06_firebase_storage.md` | Upload & download images/files with progress |
| 7 | `07_push_notifications_fcm.md` | FCM: device tokens, receiving notifications, channels |
| 8 | `08_security_rules.md` | Firestore & Storage security rules that actually protect data |
| 9 | `09_capstone_notes_app.md` | **Capstone project:** notes app with Google sign-in + cloud sync |
| 10 | `10_exercises.md` | Practice tasks for every lesson |

## What you need

- **Android Studio** (latest stable) — lesson 01 walks through install
- A **Google account** (for the Firebase console — free, no card needed)
- A physical Android device or emulator
- Basic Kotlin recommended — but every snippet is explained line by line

## How to learn from this repo

1. Go in order — each lesson builds on the previous one.
2. **Build the sample app yourself** as you read; don't just copy-paste.
3. Hit an error? Every lesson has a "Common errors" section — check there first.
4. Finish with the capstone project, then extend it with your own ideas.

## Firebase pricing note

Everything in this course fits in Firebase's **free Spark plan**
(Auth, Firestore, Storage, FCM all have generous free tiers).
You will NOT be asked for a credit card.
